Un site web moderne, réactif et professionnel conçu pour le cabinet de pédiatrie du **Dr. Yasmine Belkacem**. Ce projet a pour but de fournir aux parents une interface intuitive pour découvrir les services médicaux proposés, trouver les informations de contact, les horaires de consultation et faciliter la prise de rendez-vous.

---

## ✨ Fonctionnalités Principales (Features)

- **📱 Design Réactif (Responsive) :** Adapté à tous les écrans (Mobiles, Tablettes et Ordinateurs).
- **🚀 Hautes Performances :** Chargement rapide et navigation fluide pour une expérience utilisateur optimale.
- **🌐 Support Multilingue (i18n) :** Interface disponible en plusieurs langues (ex: Français, Arabe) pour mieux servir la communauté locale.
- **🏥 Présentation des Services :** Une section dédiée pour détailler les soins pédiatriques, les vaccinations et les suivis médicaux.
- **📞 Contact & Localisation :** Intégration de Google Maps, formulaire de contact et horaires de travail clairs.
- **🎨 Interface Moderne :** Utilisation d'animations subtiles et d'un design rassurant adapté au domaine de la santé infantile.

---

## 🛠️ Technologies Utilisées (Tech Stack)

Ce projet est développé avec les dernières technologies du web pour garantir sécurité, rapidité et maintenabilité :

- **Framework :** React.js / Next.js
- **Styling :** Tailwind CSS (pour un design épuré et sur-mesure)
- **Animations :** Framer Motion (pour des transitions fluides)
- **Icônes :** Lucide React
- **Déploiement :** Vercel

## 💻 Installation en Local (Local Development)

Si vous souhaitez exécuter ce projet sur votre machine locale, suivez ces étapes :

1. **Cloner le dépôt :**

   ```bash
   git clone https://github.com/arabiabdou453-cpu/Dr-Yasmine-Belkacem-P-diatre.git
   ```

2. **Accéder au dossier du projet :**

   ```bash
   cd Dr-Yasmine-Belkacem-P-diatre
   ```

3. **Installer les dépendances :**

   ```bash
   npm install
   # ou
   yarn install
   ```

4. **Lancer le serveur de développement :**

   ```bash
   npm run dev
   # ou
   yarn dev
   ```

5. **Ouvrir le navigateur :**
   Allez sur `http://localhost:3000` (ou le port indiqué dans le terminal) pour voir le site en action.
