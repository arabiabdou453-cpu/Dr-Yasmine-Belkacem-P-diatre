# Dr. Yasmine Belkacem — Pédiatre

Site vitrine moderne pour le cabinet pédiatrique de la Dr. Yasmine Belkacem. Il présente les soins proposés, les informations pratiques et un parcours de prise de rendez-vous clair.

## Site en ligne

**[Voir le site](https://pediatre-yasmine.vercel.app)**

## Aperçu

- Hero médical illustré et appels à l’action pour prendre rendez-vous ou contacter le cabinet.
- Services pédiatriques : consultation générale, suivi de croissance, vaccination, nourrissons, maladies infantiles, développement et urgences.
- Indicateurs de confiance, présentation du cabinet et coordonnées.
- Formulaire de demande de rendez-vous avec champs accessibles.
- Design responsive, adapté au mobile comme au bureau.

## Technologies

- [Next.js](https://nextjs.org/)
- React et TypeScript
- CSS moderne, sans bibliothèque d’interface externe

## Démarrer le projet localement

```bash
npm install
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000).

## Vérifications

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Déploiement

Le projet est hébergé sur Vercel et connecté au dépôt GitHub.
